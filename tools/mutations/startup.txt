# Mutations for the stage-and-session setup: Entity_CheckKillTiles,
# Terrain_Configure and Game_StartOrLoad. Three different self-tests judge
# them, so run it three times:
#
#     SELFTEST=--selftest-entities tools/mutate.sh tools/mutations/startup.txt
#     SELFTEST=--selftest-stages   tools/mutate.sh tools/mutations/startup.txt
#     SELFTEST=--selftest-player   tools/mutate.sh tools/mutations/startup.txt
#
# A mutation the running self-test cannot see will SURVIVE, which is correct
# and expected - what matters is that each one is killed by at least one of
# the three. tools/README.md records which.
