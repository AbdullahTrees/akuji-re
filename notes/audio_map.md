# Audio call map, recovered from akuji.exe

Generated by walking every `mov eax,[eax+0x2DC]` (DDSD1) and
`mov eax,[eax+0x2D8]` (KbgmPlayer1) in the CODE section and decoding the
register setup that follows. Not hand-transcribed.

## The two name arrays

Both are statically initialised `array of AnsiString` in DATA, reached
through a global pointer. Their lengths come from the unit finalisation at
`0x00452543`, which calls `_FinalizeArray(base, AnsiString, count)`:

| Global ptr | Array | Count | Contents |
|---|---|---|---|
| `p_SoundNames` `0x0046D0EC` | `0x00468D50` | 57 (`$39`) | `wav\*.wav` |
| `p_MidiNames` `0x0046D154` | `0x00468D14` | 15 (`$0F`) | `midi\*` |

The 57 matches `DDSD1.ChannelCount` in the form resource and the 57 files in
`wav/` exactly, with no name in one set missing from the other. The 15 matches
`KbgmPlayer1.AutoLoadMidis` in the form resource entry for entry, which also
cross-checks the DFM decode.

## TDDSD_Play @ 0x00450FD8

```
TDDSD_Play(Self: EAX, Index: EDX, Restart: CL)
  if CL = 1 then begin GetBuffer(Self, Index); Rewind end;
  GetBuffer(Self, Index);
  Play;
```

All 104 resolved call sites pass `CL = 1`, so an effect always restarts from
the beginning and never layers over itself. Reproduced in AudioMixer.

## Title_Init @ 0x0046214C, fully traced

```
Load_Stage_Assets(Self, 0)
Font_Define(0, Surfaces[0], $20, $140, 8, 8, 9, 9, $5F)
KbgmPlayer1.Play(p_MidiNames[0], 0)      // 'midi\init'
p_GameState := $14                       // -> Title_MainMenu
for i := 0 to $38 do                     // 57 buffers
  DDSD1.GetBuffer(i).SetVolume(-(10 - p_Settings[$24]) * $1C2)
```

The volume expression is the DirectSound attenuation curve in hundredths of
a decibel: full at setting 10, -45 dB at setting 0. `AudioMixer.VolumeToGain`
reproduces it and `--selftest-audio` tabulates it.

The `Font_Define` arguments match `GameFont.pas` exactly - 32 columns, 9x9
cells, 8 pixel advance, last character `$5F` - confirming constants that were
originally derived from the font sheet image.
